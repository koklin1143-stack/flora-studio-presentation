# 太平，可以怎么玩？

山西太平绣球当代产品与体验共创提案，20 页手机竖屏网页演示

公开访问地址：

https://koklin1143-stack.github.io/flora-studio-presentation/taiping-mobile-presentation/

## 使用方式

打开网页后，用手机竖屏观看效果最好

左右滑动可以翻页，点击屏幕左侧返回上一页，点击屏幕右侧进入下一页

桌面浏览器也可以用左右方向键翻页

## 文件结构

```text
index.html
styles.css
script.js
assets/images/
```

## 设计说明

整体采用黑、白、灰为主，太平朱作为唯一强调色

新版整理成 5 个章节，每页用目标、依据、规则、输入、动作或结果明确自己的论证职责

首屏使用 GSAP 驱动十二瓣绣片拼合为绣球的动画

第 16 页用自动组合动画说明有边界的选择，第 17 页用自动连接动画说明用户参与动作

所有产品图标统一使用太平朱绣球主体与深色配件关系，方便手机端快速识别

页面按手机竖屏演示设计，不按长网页阅读设计
