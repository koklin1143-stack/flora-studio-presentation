# 太平，可以怎么玩？

山西太平绣球当代产品与体验共创探索，第 01-10 页手机竖屏网页演示。

公开访问地址：

https://koklin1143-stack.github.io/flora-studio-presentation/taiping-mobile-presentation/

## 使用方式

打开网页后，用手机竖屏观看效果最好。左右滑动可以翻页，点击屏幕左侧返回上一页，点击屏幕右侧进入下一页。桌面浏览器也可以用左右方向键翻页。

## 文件结构

```text
index.html
styles.css
script.js
assets/images/
```

## 图片替换

把后续照片放入 `assets/images/`，并使用以下文件名即可自动显示。文件暂时不存在时，页面会显示中文占位，不影响演示。


## 设计说明

整体采用黑、白、灰为主，太平朱作为唯一强调色。每页只保留一个主要判断，用更大的标题和更清楚的段落关系突出重点。页面按手机竖屏演示设计，不按长网页阅读设计。
