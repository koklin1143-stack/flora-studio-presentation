# 太平，可以怎么玩？

山西太平绣球当代产品与体验共创提案，20 页手机竖屏网页演示

公开访问地址：

https://koklin1143-stack.github.io/flora-studio-presentation/taiping-mobile-presentation/

## 使用方式

打开网页后，用手机竖屏观看效果最好

左右滑动可以翻页，点击屏幕左侧返回上一页，点击屏幕右侧进入下一页

桌面浏览器也可以用左右方向键翻页

## 文件结构

```text

styles.css

vendor/gsap.min.js
assets/images/
```

## 设计说明

整体采用黑、白、灰为主，太平朱作为唯一强调色

新版围绕 4 个问题展开：为什么值得重新做、绣球本身怎么玩、购买过程怎么更有意思、买完以后留下些什么

首屏使用本地 GSAP 文件驱动十二瓣绣片拼合为绣球的动画，减少外部 CDN 加载失败的风险

封面增加轻量阅读提示，后续页码保留左右箭头，方便现场自行翻页

第 17 页保留“不知道，随便来一个”的随机小太平交互

第 18 页保留透光卡互动，并说明所选祝福如何进入小卡

所有产品图标统一使用太平朱绣球主体与深色配件关系，方便手机端快速识别

页面按手机竖屏演示设计，不按长网页阅读设计
