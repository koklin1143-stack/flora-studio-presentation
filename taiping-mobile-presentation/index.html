02 / 绣球本身怎么玩

配件服务于识别， 绣球始终是主角

平面件 耳朵 / 爪 / 佛手 / 花
半立体件 轻填充的小动物部分
垂饰件 流苏 / 小珠 / 小挂件
太平绣球 约 75-85% 小配件 约 15-25%

建议绣球保持 75-85% 的视觉占比，配件只负责补充特征

03 系列怎么成立
容易出现

先有产品，
再补主题

现成绣球

说它属于某个星座

最后补一句寓意

建议采用

先定表达，
再形成造型

先确定想表达什么

找到对应视觉特征

再决定配件和组合

让每一款的意义、特征与造型从一开始就对应

03 / 系列怎么成立

“十二” 是一套可延展框架

十二生肖

动物的耳、角、爪、尾、动作

兔耳 / 虎爪 / 猴子趴住
十二星座

最容易认出的星座特征

白羊角 / 巨蟹钳 / 天蝎尾
十二种小太平

今天真正想顺一点的小事

睡得着 / 赶得上 / 早点回

无论选择哪一种主题，都需要先建立清晰的系列理由

03 / 系列怎么成立

一套公式 控制系列一致性

系列主题 + 对应特征 + 太平绣球 = 完整一款

星座+白羊角+绣球=白羊款

小太平+跑路腿+绣球=赶得上

04 / 买绣球的过程怎么玩

整段体验， 控制在 1-3 分钟

  1. 01
    表达需求

    选择用途，再选一句当下最需要的祝愿

  2. 02
    确认组合

    选择绣球与系列配件，形成一套合理搭配

  3. 03
    亲手完成

    装上最后一个挂扣或配件，留下参与感

  4. 04
    带走故事

    获得与这颗绣球对应的纹样卡与祝福

不做复杂测试，不要求长时间手作，确保门店与活动现场都能顺畅完成
