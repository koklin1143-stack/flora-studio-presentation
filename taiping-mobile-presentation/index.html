02 绣球本身怎么玩

同一颗球，通过六种关系获得角色

趴住
抱住
叼住
托起
戴上
绕住

结论：球体不变，动作关系决定新品的第一眼识别

产品规则 / 配件只补充特征

配件服务于识别， 绣球始终是主角

平面件 贴合球面：耳、爪、花瓣、角
半立体件 轻微凸起：动物头部与身体局部
垂饰件 向下延伸：流苏、小珠与小挂件
太平绣球 约 75-85% 小配件 约 15-25%

控制原则：绣球保持 75-85% 的视觉占比，配件只负责补充识别

我们的流程 / 放到太平绣球里

自己的太平， 这样得到

  1. 01先说今天想让什么顺一点最近总是加班
  2. 02给出 2-3 个“小太平”准时下班 / 少点烦心事 / 早点回家
  3. 03选一颗喜欢的绣球看颜色、纹样和大小
  4. 04选一个对应小配件生肖 / 星座 / 小太平系列
  5. 05自己完成最后一步扣上 / 吸上 / 挂上
  6. 06得到一张对应小卡纹样和祝福一起留下
  7. 07把这一颗“太平”带走1-3 分钟，足够产生一次记忆

入口问题 / 不做复杂问卷

今天， 你最想哪件事顺一点？

比如：今天别下雨

不是测你是谁，只问今天想让什么顺一点
