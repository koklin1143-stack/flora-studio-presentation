02 绣球本身怎么玩 / 产品机制

球不变， 角色怎么和它相处可以变

同一颗太平绣球 趴 / 抱 / 托 / 绕 / 戴 产生不同角色 继续加入生肖 / 动物 / 水果 / 节气 / 联名
趴住

叼住

绕住

这是可持续扩展的产品机制，不是六个孤立造型

产品规则 / 配件只补充特征

配件服务于识别， 绣球始终是主角

平面件 贴合球面：耳、爪、花瓣、角
半立体件 轻微凸起：动物头部与身体局部
垂饰件 向下延伸：流苏、小珠与小挂件
太平绣球 约 75-85% 小配件 约 15-25%

控制原则：绣球保持 75-85% 的视觉占比，配件只负责补充识别

03 买绣球的过程怎么更有意思

不只改“球”， 也改买到它的过程

让用户从“挑一个产品”，变成“得到一颗和自己有关的太平”

产品
人
自己的结果

案例怎么用 / 一

先问人的需要， 产品才会和人有关

气味邮局

它做了什么先问“你现在想要什么”，再给出气味方向

我们学到了什么先问当下需要，产品才会和人产生关系

变成太平绣球购买之前先让用户说“今天想让什么顺一点”

装杯 / 组合型案例

它做了什么从已有材料里重新组合，得到个人结果

我们学到了什么不一定做昂贵定制，现有材料组合也能有个人感

变成太平绣球基础绣球 + 小配件 + 不同祝福，组合出自己的这一颗

案例怎么用 / 二

参与不用复杂， 最后一步就够

折纸完成类体验

它做了什么用户不用从头做，只完成最后一个简单动作

我们学到了什么完成最后一步，也会有“这是我完成的”感觉

变成太平绣球复杂工艺仍由传承人完成，游客只安装或组合最后一步

不再纠结 / 轻互动案例

它做了什么一个问题，一次选择，马上得到结果

我们学到了什么互动不能做成长测试或复杂问卷

变成太平绣球“今天你最想让什么顺一点？”→ 推荐 2-3 个结果

所以，我们不让游客“做一颗绣球”，而是让他“完成自己的这一颗太平”

我们的流程 / 放到太平绣球里

自己的太平， 这样得到

  1. 01先说今天想让什么顺一点最近总是加班
  2. 02给出 2-3 个“小太平”准时下班 / 少点烦心事 / 早点回家
  3. 03选一颗基础绣球看颜色、纹样和大小
  4. 04选一个外部角色或配件生肖 / 星座 / 小太平 / 节气主题
  5. 05自己完成最后一步扣上 / 吸上 / 挂上
  6. 06得到一张对应小卡纹样和祝福一起留下
  7. 07把这一颗“太平”带走1-3 分钟，足够产生一次记忆

入口问题 / 不做复杂问卷

今天， 你最想哪件事顺一点？

比如：回家的路别堵

不是测你是谁，只问今天想让什么顺一点
