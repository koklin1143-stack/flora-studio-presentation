02 / 绣球本身怎么玩

配件要轻， 球还是主角。

平面件 耳朵 / 爪 / 佛手 / 花
半立体件 轻填充的小动物部分
垂饰件 流苏 / 小珠 / 小挂件
太平绣球 约 75-85% 小配件 约 15-25%

贵的是绣球，配件负责让它多一点变化。

02 / 绣球本身怎么玩

04 / 买绣球的过程怎么玩

一颗太平， 可以这样被得到。

  1. 今天想要什么？
  2. 找到几个方向
  3. 选择绣球
  4. 选一个小配件
  5. 自己完成最后一下
  6. 得到对应小卡

整个过程控制在 1-3 分钟，不做复杂测试，不做长时间手作。
